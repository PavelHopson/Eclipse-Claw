# Контракт ограниченного плана агентов

`eclipse-claw-audit::agent_plan` принимает plan-объект `eclipse.agent-run-plan.v1`,
который формирует Automation Audit в Eclipse AI Hub.

Импорт — только проверка данных. Он не запускает агента, не выдаёт разрешения и
не меняет конфигурацию runtime.

## Fail-closed границы

- `executionAllowed` обязан оставаться `false`;
- принимаются только три фиксированные роли аудита;
- сеть, запись в файловую систему, внешние действия и секреты — только `deny`;
- шаги, вызовы модели, токены, стоимость, время и параллелизм ограничены локальным максимумом;
- причины остановки передаются стабильными machine-readable кодами;
- неизвестные поля, новые permissions и расширенный budget отклоняются целиком.

Реальный исполнитель должен быть отдельным модулем с server-side учётом budget,
tenant isolation, append-only audit log и явным human approval для каждого класса
действий. Валидный plan сам по себе не является разрешением на выполнение.
